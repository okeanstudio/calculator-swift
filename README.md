# Калькулятор

Калькулятор с интерфейсом iOS на Swift

## Возможности
- Базовые математические операции
- Поддержка десятичных дробей
- Отрицательные числа
- Проценты
- Тёмная тема

## Технологии
- SwiftUI
- MVVM архитектура
- Combine

## Установка
1. Клонировать репозиторий
2. Открыть проект в Xcode
3. Запустить на симуляторе или устройстве
